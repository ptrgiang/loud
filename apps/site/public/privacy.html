Privacy and usage reports

Loud runs on your computer. Your sessions, posts and numbers stay there, and Loud talks to the platforms you connect. The one thing it can send us is a small usage report, and only if you say yes.

The question

The first time you open Loud, it asks whether to share usage. Until you answer, nothing is counted or sent. If you choose Don't share, that is the end of it. You can change your answer any time in Settings, under Usage reports, where Loud also shows the exact report it would send next.

What a report contains

One report a day, at most, sent to loud.trysometh.ing/api/usage:

  • install: a random id made on your computer when you turn sharing on. It is not tied to your accounts, your computer or anything else.
  • version, os and arch: which Loud you run.
  • platforms: for Threads, Instagram, Facebook Page and X, whether it is connected and whether it is included in runs.
  • collect: since the last report, how many collection runs on each platform worked, failed, or stopped at a login check, captcha or rate limit.
  • agent and updateChecks: whether those two features are on.

An example, with a made-up id:

{
  "v": 1,
  "install": "00000000-0000-4000-8000-000000000000",
  "version": "0.1.1",
  "os": "win32",
  "arch": "x64",
  "platforms": {
    "threads": { "connected": true, "included": true },
    "ig": { "connected": false, "included": false },
    "fb": { "connected": false, "included": false },
    "x": { "connected": true, "included": true }
  },
  "collect": {
    "threads": { "runs": 2, "done": 2, "failed": 0, "blocked": 0 },
    "ig": { "runs": 0, "done": 0, "failed": 0, "blocked": 0 },
    "fb": { "runs": 0, "done": 0, "failed": 0, "blocked": 0 },
    "x": { "runs": 1, "done": 0, "failed": 0, "blocked": 1 },
    "listen": { "runs": 0, "done": 0, "failed": 0, "blocked": 0 }
  },
  "agent": false,
  "updateChecks": true
}

What is never sent

  • Handles, page names, profile details, posts, or any number from your accounts.
  • Anything you typed: drafts, keywords, settings text, or what the agent said.
  • Error messages, file paths or the name of your computer.

The server refuses any report with a field that is not on the list above, so a change to what Loud sends has to show up here and in the source first.

How it is kept

  • Reports are stored in a Cloudflare D1 database, one row per install id and UTC day.
  • Your IP address reaches Cloudflare, as with any website, but the server does not read or store it, and request logging is off.
  • Rows are deleted after 400 days.
  • Turning sharing off asks the server to delete every report from your install id, then deletes the id and the counts on your computer. Turning it on again makes a new id.
  • Only totals are shown, on the home page, from loud.trysometh.ing/api/stats. Single reports are never published.

Other requests Loud makes

  • The platforms you connect, through their own pages.
  • GitHub Releases, if you turn on update checks: GitHub sees your IP address and Loud's version.
  • The agent, if you turn it on, runs through Claude Code or Codex signed in on your computer, and their own terms apply.

This website

This site sets no cookies and runs no analytics. To show the right download button, your browser asks GitHub for the latest release, so GitHub sees that request.
